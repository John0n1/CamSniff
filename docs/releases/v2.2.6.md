# CamSniff 2.2.6

CamSniff 2.2.6 turns the latest audit findings into a safer and more reliable
release. The central improvement is strict scan-scope containment: passive
discoveries, metadata retrieval, and follow-up probes are accepted only when
their IPv4 destination is inside the targets selected by the operator.

## Highlights

| Area | What changed |
| --- | --- |
| Scope safety | Enforces declared IPv4 targets across active scans, passive discoveries, SSDP descriptions, redirects, and follow-up probes. |
| Detection quality | Removes port-only vendor assignments and evidence-free camera classifications. |
| Parsing | Uses structural Masscan JSON parsing and a real CSV parser for quoted TShark output. |
| Credentials | Bounds probing per host, URL-encodes RTSP credentials, validates captured media, and redacts secrets from reports. |
| Packaging | Adds a native Arch Linux package and validates both Debian and Arch packages in CI. |

## Security hardening

- Rejects out-of-scope addresses before they can become candidates or probe
  destinations.
- Restricts SSDP description URLs and redirects to the authorized target set,
  with a 1 MiB response limit.
- Creates result directories with mode `700` and sensitive files with mode
  `600`.
- Redacts passwords and URL user information from Markdown and HTML reports.
- Supplies GPG passphrases through a file descriptor instead of a visible
  command-line argument.

## Correctness and detection

- Preserves TCP and UDP protocol/state separately in discovery and IVRE data.
- Interprets captured HTTP and RTSP requests directionally so clients are not
  promoted to camera servers.
- Corrects Nmap and Masscan summary counts and reports Avahi failures clearly.
- Fixes credential-attempt deduplication, FFmpeg timeout compatibility, RTSP
  user-information encoding, and per-host probe budgets.
- Improves the bundled RTSP NSE script across common RTSP ports and response
  handling.

## Upgrade notes

- Discovery documents now declare `schema_version: 2` and include typed
  `services` entries. The legacy `ports` field remains for compatibility.
- Packaged installations write results to `/var/lib/camsniff/results`; source
  checkouts continue to use `dev/results`.
- Masscan remains optional and is disabled cleanly when unavailable.
- CoAP support is now explicitly opt-in through `make build-coap`.

## Install

Debian or Ubuntu:

```bash
curl -LO https://github.com/John0n1/CamSniff/releases/download/v2.2.6/camsniff_2.2.6_all.deb
sudo apt install ./camsniff_2.2.6_all.deb
```

Arch Linux:

```bash
curl -LO https://github.com/John0n1/CamSniff/releases/download/v2.2.6/camsniff-2.2.6-1-any.pkg.tar.zst
sudo pacman -U ./camsniff-2.2.6-1-any.pkg.tar.zst
```
