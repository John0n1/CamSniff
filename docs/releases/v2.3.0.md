# CamSniff 2.3.0

CamSniff 2.3.0 is the evidence-engine release. It replaces split preliminary
and final heuristics with one inspectable confidence model, adds adaptive
follow-up planning, speaks RTSP directly, expands ONVIF enumeration, and
introduces declarative vendor fingerprint modules.

## Highlights

- Structured positive and negative evidence with score subtotals.
- One confidence model for smart targeting and final classification.
- Per-host HTTP, ONVIF, and streaming follow-up plans.
- Native RTSP `OPTIONS`/`DESCRIBE` verification and SDP parsing.
- Bounded ONVIF identity, service, capability, scope, interface, and time
  enumeration.
- YAML fingerprints for Axis, Dahua, and Hikvision.
- 35 focused behavioral and integration regression tests.

## Safety properties

- All active work remains constrained to the operator's authorized target set.
- RTSP identification never authenticates, starts playback, or retrieves media.
- ONVIF enumeration stops when authentication is required.
- Native protocol responses and request counts are bounded.
- Shared ports cannot independently identify a vendor.
- Credential material remains redacted from rendered reports.

## Compatibility

Discovery schema version 2 remains current. Existing `score`, `level`,
`classification`, `reasons`, and `signals` confidence fields are preserved.
The new `evidence`, `positive_score`, `negative_score`, and `probe_plan` fields
are additive. The CSV camera catalogue remains supported alongside YAML vendor
fingerprints.

## Installation

Debian/Ubuntu:

```bash
sudo apt install ./camsniff_2.3.0_all.deb
```

Arch Linux:

```bash
sudo pacman -U camsniff-2.3.0-1-any.pkg.tar.zst
```

Run only against systems and networks you are explicitly authorized to assess.
